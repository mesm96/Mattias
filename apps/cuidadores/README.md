# MATTIAS Cuidadores

Aplicación para cuidadores profesionales de perros.

## Funcionalidades

- Registro e inicio de sesión.
- Verificación obligatoria de identidad.
- Perfil profesional.
- Publicación de servicios.
- Gestión de reservas.
- Calendario de disponibilidad.
- Chat con clientes.
- Gestión de ganancias.
- Comisión MATTIAS del 15%.

## Diseño

- Verde salvia: #718D72
- Verde crema: #DDE8D5
- Crema: #F3F0E7

## Tecnología

Flutter para Android y iPhone.
