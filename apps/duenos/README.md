# MATTIAS Dueños

Aplicación móvil para propietarios de perros.

## Funcionalidades

- Registro e inicio de sesión.
- Registro de mascotas.
- Búsqueda de cuidadores.
- Reservas y pagos.
- Chat.
- Seguimiento de servicios.
- Calificaciones.

## Diseño

- Verde salvia: #718D72
- Verde crema: #DDE8D5
- Crema: #F3F0E7

## Tecnología

Flutter para Android y iPhone.
