# MATTIAS DATABASE

Base de datos central de MATTIAS.

## Tablas principales

- users: usuarios y administradores.
- owners: propietarios de perros.
- caregivers: cuidadores.
- pets: mascotas.
- services: servicios ofrecidos.
- bookings: reservas.
- payments: pagos.
- reviews: calificaciones.
- messages: conversaciones.
- verifications: documentos y verificaciones.
- notifications: notificaciones.

## Reglas comerciales

- Comisión MATTIAS: 15%.
- Ganancia del cuidador: 85%.

## Seguridad

- Protección de datos personales.
- Acceso según roles.
- Verificación obligatoria de cuidadores.
- Registro de operaciones.

Colombia.
