MATTIAS – Cuidado de Perros

Cuidamos lo que más amas.

MATTIAS es una plataforma colombiana que conecta propietarios de perros con cuidadores independientes.

Plataformas
apps/duenos: aplicación para propietarios.
apps/cuidadores: aplicación para cuidadores.
admin: portal web privado de administración.
backend: servicios y API.
database: estructura y migraciones de datos.
docs: documentación del proyecto.
Identidad visual
Verde salvia: #718D72
Verde crema: #DDE8D5
Crema: #F3F0E7
Beige: #D9CBB4
Estilo: minimalista premium.
Modelo comercial
Comisión de plataforma: 15%.
Participación del cuidador: 85% antes de otros costos.
Verificación obligatoria de cuidadores.
Moneda: COP.
Cobertura: Colombia.
Tecnología
Flutter: aplicaciones Android y iOS.
Aplicación web independiente para administración.
Backend compartido.
Base de datos centralizada.
Estado

Proyecto en fase inicial de desarrollo.
