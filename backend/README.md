# MATTIAS BACKEND

Sistema central de la plataforma MATTIAS.

## Funciones

- Gestión de usuarios.
- Autenticación.
- Gestión de mascotas.
- Gestión de cuidadores.
- Verificación de identidad.
- Reservas.
- Pagos.
- Comisión del 15%.
- Mensajería.
- Notificaciones.
- Gestión de reclamaciones.

## Seguridad

- Acceso por roles.
- Protección de datos.
- Validación de permisos.
- Registro de actividad.

## Integraciones futuras

- Supabase.
- Google Maps.
- Wompi.
- Firebase.
